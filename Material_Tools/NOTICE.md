# Material Manager - notice

`Material_Tools/` is a Python rewrite of **Material Manager v5.2.0** by **Dennis Porter**
(<https://github.com/Bartalon/Material-Manager>), which is released under the **GNU General Public License v3.0**.

What comes from the original
- the feature set and workflow (material list, marks, channel control, presets, ID map baker, tools),
- the channel attribute tables, the preset file format and the contents of `Data/mm_material_presets.txt`,
- the icons in `Icons/` (copied from the original package).

What is new in this version
- written in Python (Maya 2018 - 2025, Python 2 and 3) instead of MEL,
- a separate window using the HSTool visual style,
- Standard Surface support, materials created without the Hypershade, a tested core (`Scripts/Python/material_core.py`).
